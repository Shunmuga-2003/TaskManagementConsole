Functional Requirements:
The system should allow users to create, update, and delete tasks with title, description, due date, priority, and status.
The system should support composite tasks where a task can contain multiple subtasks (recursive structure).
Users should be able to assign tasks to other users and update task details including title, description, due date, and priority.
The system should implement a state machine for task workflow with state-specific behavior.
Users should be able to view tasks assigned to them, tasks they have created, and check delayed tasks.
The system should support searching and filtering tasks with flexible sorting strategies (Strategy Pattern).
The system should automatically log all task changes and notify observers of status updates (Observer Pattern).
Users should be able to categorize tasks using tags and add comments for collaboration.
The system should handle concurrent access to tasks and ensure data consistency.
Users should be able to view task distribution by priority, status, and tags.
